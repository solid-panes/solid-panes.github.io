Demos

End-to-end proofs of the LION → urn-solid → solid-schema → solid-panes → LOSOS chain. Each demo loads a JSON-LD data island that declares only @type (no $schema) — auto-schema looks up the urn:solid type and patches in the matching solid-schema URL, then LOSOS renders the form.

  • Note Schema-driven editor for urn:solid:Note via the generic schema-pane
  • Person Schema-driven editor for urn:solid:Person via the generic schema-pane
  • Vtodo Custom todo-pane.js for urn:solid:Vtodo — registry entry can route to a bespoke pane when warranted

What to look for

  1. Open browser devtools. The console logs how many data islands auto-schema patched.
  2. View source on the data file (linked from the page) — it has @type but no $schema.
  3. The Edit tab appears auto-generated from the matching solid-schema URL.
  4. The Source tab shows the raw data, including the $schema field that auto-schema inserted.
